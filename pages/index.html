Build a weather replay.

Archived Level II radar and KSC observations, prepared for one UTC timeline in GR2Analyst.

Choose your scenario

Open the build form on GitHub to choose the UTC window, radar site, wind towers, field mills, and MERLIN lightning trail.

Open scenario build form

Sign in to GitHub, then select Run workflow.

  1. Enter start and end in 24-hour UTC, such as 2024-06-25T21:00.
  2. Choose your layers and run the build.
  3. Wait for the finished ZIP, then download and extract it once.

Downloads include radar, placefiles, needed icons, and GR instructions. Raw CSVs and profilers are excluded. A partial package identifies missing sources in its README.

Loading a scenario in GR2Analyst
  1. Extract the complete ZIP to a permanent folder and read README.txt.
  2. When wind icons are included, run FIX_ICON_PATHS.cmd or follow the manual icon-path instructions.
  3. Stop live polling and open the files in the radar folder.
  4. Add replay_clock_check.txt in Placefile Manager. Verify that its time changes as you step through radar.
  5. Add the other placefiles and start the loop.

Playback still needs verification in your installed GR2Analyst 3.0, 3.2, or 3.4. ZIP validation confirms file integrity, not GR compatibility. Display colors are not launch criteria.
